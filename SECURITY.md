# Security

Report a suspected vulnerability through [GitHub private vulnerability reporting](https://github.com/104-bookwyrm/WidgetBoard/security/advisories/new). This route requires a GitHub account and depends on private vulnerability reporting being enabled for the repository. Do not include secrets or personal data in a public issue.

The project has no anonymous security intake. If GitHub does not offer the private reporting form, use the repository's [problem report form](https://docs.google.com/forms/d/e/1FAIpQLScncGOaM59oGvswPvq5aHDaC-M7M4NQoPuyh_y6Rz5p2qZV_w/viewform) and ask for a private contact route without posting vulnerability details publicly.
