# Support

- Report bugs and request changes in [GitHub Issues](https://github.com/104-bookwyrm/WidgetBoard/issues/new).
- Use the in-app **Settings → About → Report a problem** form, or open the [problem report form](https://docs.google.com/forms/d/e/1FAIpQLScncGOaM59oGvswPvq5aHDaC-M7M4NQoPuyh_y6Rz5p2qZV_w/viewform) directly.

The in-app form includes application information. Review the contents before submitting. Do not include passwords, private keys, or other secrets.
